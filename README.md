## Featured Projects

### AtlasFX  
**A global money weather map for currency stress detection.**

AtlasFX is a full-stack financial ML dashboard that combines FX movement, headline sentiment, and macro indicators into an explainable country-level currency stress signal.

It is not trying to predict exact currency prices. The goal is early stress detection: where pressure is building, why the model thinks it matters, and which signals are driving the score.

**Stack:** Next.js · React · TypeScript · Tailwind · FastAPI · Pandas · NumPy · scikit-learn · Frankfurter FX · Google News RSS · GDELT · World Bank API

**Built:**  
Country-level risk scoring · FX volatility/depreciation features · local NLP headline stress model · logistic regression and random forest FX-regime classifiers · backend/frontend validation · CI checks

[View repo](https://github.com/dhruvtoprani/atlasfx)

### PreFlight AI  
**AI stakeholder intelligence for PM and TPM kickoff readiness.**

PreFlight is a Slack-native AI workflow system that helps PMs and TPMs pressure-test initiatives before kickoff. A user submits a structured initiative brief, and PreFlight reviews it through role-based stakeholder lenses using Jira, Confluence, and team context.

It returns risks, blockers, owners, unresolved questions, evidence labels, and a recommended first-meeting agenda.

**Stack:** Python · FastAPI · Pydantic · Slack · Jira API · Confluence API · OpenAI API · retrieval · run persistence · dashboard UI

**Built:**  
Role-based multi-agent review · evidence-backed vs inferred concern labels · deterministic fallback mode · run history · dashboard drilldown · redacted APIs

[View repo](https://github.com/dhruvtoprani/preflight-AI)

### DocFlow MCP  
**An MCP-native documentation clipper for AI coding workflows.**

DocFlow turns noisy documentation pages into clean, implementation-ready context for ChatGPT, Claude, Cursor, and agentic coding tools.

It strips away repeated navigation, UI chrome, and irrelevant docs clutter so coding agents get the context they actually need.

**Stack:** TypeScript · Node.js · MCP · HTTP API · Vercel · Chrome extension wrapper

**Built:**  
MCP endpoint · live clip endpoint · Chrome extension wrapper · documentation synthesis modes · evaluation artifacts

[View repo](https://github.com/dhruvtoprani/docflow-mcp)
